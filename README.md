# AI video production

Pipeline that turns a script into a finished short video.

## What it does

- Script and storyboard templates, with an automatic check of the opening hook.
- Each video is an HTML composition animated with GSAP and rendered to MP4.
- AI avatar plus image and video generation models for the shots.
- The same system makes Instagram carousels.

## Stack

HyperFrames, HTML, GSAP, Python, FFmpeg, HeyGen, generative image and video models.
